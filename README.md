# XOP 代理店 業務ポータル

クラックス合同会社の代理店（施工の仲間）と本部が使う業務のしくみです。

## 施工完了のLINE報告（試験運用版）

施工が終わったら、施工責任者がLINEから完了報告を送り、本部が確認してOKなら正規施工証明書を出す、という流れを試すためのものです。
クラックスの現場では、同じ報告で出面（だれが何日）も記録します。

| 画面 | ファイル | 使う人 |
| --- | --- | --- |
| 施工完了報告（LINEの中で開く） | `web/index.html` | 代理店の施工責任者 |
| 報告の確認・現場とメンバーの登録・出面の一覧 | `web/hq.html` | 本部 |

```
web/                       画面（そのまま置くだけで動く。組み立て作業は不要）
  config.js                LIFF ID と API の場所（立ち上げのときに書きかえる）
  common.js                共通の処理・お試しモード
  app.js / index.html      代理店の画面
  hq.js / hq.html          本部の画面
supabase/
  migrations/              データベースを作るSQL
  functions/api/           サーバー側の処理（LINEのログイン確認、保存、LINEへのお知らせ）
docs/setup.md              立ち上げの手順
```

### お試しモード

`web/config.js` の `liffId` が空のときは、LINEやSupabaseなしで動く「お試しモード」になります。
データはそのブラウザの中だけに保存されます。画面の上の帯で「使う人」を切りかえたり、本部の画面に移ったりできます。

```
cd web
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

### お客様の情報の扱い

- お客様の名前・住所・電話は持ちません。現場は「○○マンション 共用廊下」のような呼び名と現場ID（T-0012 など）だけで扱います。
- 写真はLINEのトークには送らず、Supabase（東京リージョン）の外から見えない保管場所に直接保存します。表示は1時間だけ使えるリンクで行います。
- データベースはすべてサーバー側の処理を通して読み書きし、ブラウザからは直接読めません。

本番での立ち上げは [docs/setup.md](docs/setup.md) を見てください。
